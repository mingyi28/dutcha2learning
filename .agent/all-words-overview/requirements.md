# 需求文档

## 引言
本需求旨在为荷兰语学习应用的"复习中心"页面增加一个"所有单词"总览入口，让用户能够按日期分组浏览全部1200个单词的学习计划和进度，并支持快速跳转复习。

### 改动范围
- **复习中心页面（Tab 2）**：新增"所有单词"入口，移除与打卡记录重复的"近一周学习记录"
- **打卡记录页面（Tab 3）**：**保持不变**，维持现有的日历打卡视图、单词详情弹窗等全部功能
- **今日学习页面（Tab 1）**：**保持不变**

### 改造后复习中心的定位
| 入口 | 说明 |
|------|------|
| 生词本 | 复习被标记为"生词"的单词（已有功能，保留） |
| 所有单词 | **新增**，按日期分组浏览全部1200个单词，查看学习计划和进度 |

## 需求

### 需求 1：复习页面改造——新增"所有单词"入口并移除重复功能

**用户故事：** 作为一名荷兰语学习者，我希望复习中心页面提供"生词本"和"所有单词总览"两个核心入口，以便我快速进入不同的复习场景。

#### 验收标准

1. **WHEN** 用户进入"复习中心"，**THEN** 页面应当展示两个核心入口卡片："生词本"和"所有单词"。
2. **WHEN** 展示"所有单词"卡片，**THEN** 应当显示学习总进度概要（如"已学 X / 1200 词，预计 Y 天后学完"）。
3. **IF** 复习中心页面当前存在"近一周学习记录"列表，**THEN** 应当将其移除，因为"所有单词总览"已覆盖此功能。
4. **IF** 用户点击"所有单词"卡片，**THEN** 系统应当进入全部单词总览视图。

### 需求 2：按日期分组展示全部单词

**用户故事：** 作为一名用户，我希望看到所有单词按照日期分组排列，清楚知道每天要学什么、已经学了什么、以及未来还有多少。

#### 验收标准

1. **WHEN** 用户进入"所有单词"总览视图，**THEN** 系统应当将全部1200个单词按每组10个分组，并为每组标注日期。
2. **IF** 某组单词已被学过（对应日期已过且有学习记录），**THEN** 该日期组应标记为"已完成"状态，显示实际学习日期。
3. **IF** 某组单词是今日目标，**THEN** 该日期组应标记为"今日学习"状态，并高亮显示。
4. **IF** 某组单词尚未学习，**THEN** 该日期组应标记为"计划中"状态，显示预计学习日期。
5. **WHEN** 展示每个日期分组，**THEN** 应当显示该组包含的单词列表（荷兰语、中文、英文）。

### 需求 3：动态日期调整逻辑

**用户故事：** 作为一名用户，我希望预计学习日期能根据我的实际学习节奏自动调整，而不是固定不变的。

#### 验收标准

1. **IF** 用户某天实际学习了多组单词（如今天学了20个），**THEN** 后续所有未学组的预计日期应当相应提前。
2. **IF** 用户某天没有进行学习，**THEN** 后续所有未学组的预计日期应当相应顺延一天。
3. **WHEN** 计算预计日期，**THEN** 系统应当基于以下规则：
   - 已学完的组使用实际学习日期
   - 从最后一次学习日期的下一天开始，按每天10个单词的节奏排列后续未学组
   - 如果今天还没学但有今日目标，今天作为下一个待学日期
4. **WHEN** 显示预计完成全部单词的日期，**THEN** 应当基于上述动态计算给出准确预估。

### 需求 4：快速跳转复习功能

**用户故事：** 作为一名用户，我希望在浏览所有单词列表时，能快速跳转到某个日期组进行复习。

#### 验收标准

1. **WHEN** 用户点击某个"已完成"日期组的复习按钮，**THEN** 系统应当进入该组的复习模式（复用现有的认读+拼写复习流程）。
2. **WHEN** 用户点击"今日学习"日期组，**THEN** 系统应当跳转回"今日学习"页面继续学习。
3. **IF** 用户点击"计划中"的未来日期组，**THEN** 不触发任何跳转操作，或者显示提示"该组尚未解锁"。

### 需求 5：列表导航与用户体验

**用户故事：** 作为一名用户，我希望在1200个单词的长列表中能快速定位到当前进度位置，避免大量滚动。

#### 验收标准

1. **WHEN** 用户进入"所有单词"总览视图，**THEN** 系统应当自动滚动到"今日学习"或最近一个未完成的日期组位置。
2. **IF** 列表较长，**THEN** 每个日期分组应当支持折叠/展开，默认"已完成"的组折叠，"今日"和"计划中"的组展开（或仅展开今日和附近几组）。
3. **WHEN** 用户点击返回按钮，**THEN** 系统应当返回到复习中心列表页。
4. **IF** 展示总览页面顶部，**THEN** 应当显示一个进度概览区域（进度条、已学/总数、预计完成日期）。

### 需求 6：数据一致性

**用户故事：** 作为一名用户，我希望所有单词总览中的数据与实际学习进度保持一致。

#### 验收标准

1. **WHEN** 用户从"今日学习"页面完成学习后切换到"所有单词"总览，**THEN** 总览应当反映最新的学习进度。
2. **IF** 用户通过"学习下一组"加速学习，**THEN** 总览中的已完成组和预计日期应当实时更新。
3. **WHEN** 用户重新进入"所有单词"总览（如通过 KeepAlive 激活），**THEN** 系统应当重新计算并刷新数据。
